# own-rich-calendar

> Your own rich calendar

[![NPM](https://img.shields.io/npm/v/own-rich-calendar.svg)](https://www.npmjs.com/package/own-rich-calendar) [![JavaScript Style Guide](https://img.shields.io/badge/code_style-standard-brightgreen.svg)](https://standardjs.com)

## Install

```bash
npm install --save own-rich-calendar
```

## Usage

```tsx
import React, { Component } from 'react'

import MyComponent from 'own-rich-calendar'
import 'own-rich-calendar/dist/index.css'

class Example extends Component {
  render() {
    return <MyComponent />
  }
}
```
